## Context

Kanban MVP 已完成基础功能（四列看板、任务 CRUD、状态切换、详情面板）。当前存在三个 UI 问题：
1. 看板区域未铺满 MainLayout 剩余高度，底部有大片空白
2. 任务卡片无 ID 标识，不便引用
3. 新建任务的创建时间未在卡片和面板中展示

## Goals / Non-Goals

**Goals:**
- 看板容器自适应填满视口剩余高度
- 每张卡片显示任务 ID（格式 `#N`）
- 创建时间在查看模式和编辑模式中均可见

**Non-Goals:**
- 不改变任务数据模型（ID 已存在，仅需前端展示）
- 不改变 MainLayout 整体结构
- 不引入新的组件库或依赖

## Decisions

### 1. 看板高度铺满

**方案**: MainLayout 使用 `flex flex-col`，`<main>` 设置 `flex-1 overflow-hidden`；Board 组件使用 `h-full` 填满父容器。

**理由**: 最小改动，利用已有 flex 布局，无需 JavaScript 计算高度。

### 2. 卡片 ID 显示

**方案**: 在卡片标题前显示 `#ID`（如 `#1`），使用 `md-label-small` + `on-surface-variant` 颜色，与标题同行或上方。

**理由**: ID 是辅助信息，不应抢标题视觉权重。使用小字号 + 低对比度颜色。

### 3. 创建时间展示

**方案**: 查看模式已显示创建时间；编辑模式在标题下方增加创建时间行（只读文本）。

**理由**: 创建时间是元数据，编辑时不应修改，仅展示。

## Risks / Trade-offs

- [布局兼容性] → 使用 CSS flex 而非 JS 计算，无运行时风险
- [ID 格式] → 使用数字 ID 而非 UUID 前缀，简洁但依赖数据顺序
