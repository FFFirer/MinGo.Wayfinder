# 变更提案（Changes）

本目录存放所有变更提案（Proposals）。

## 工作流程

1. **创建提案**：在 `changes/` 目录创建新的变更提案文档
2. **评审提案**：团队评审提案内容
3. **接受/拒绝**：更新提案状态
4. **应用变更**：使用 `/opsx:apply` 将接受的变更应用到 `specs/`
5. **归档**：使用 `/opsx:archive` 归档已完成的变更

## 文件命名

变更提案文件使用以下命名格式：

```
changes/
├── README.md                      # 本文件
├── add-user-authentication.md     # 新增功能
├── modify-order-flow.md           # 修改现有功能
└── remove-deprecated-api.md       # 移除功能
```

## 提案状态

- 📋 **Proposed**：已提出，待评审
- ✅ **Accepted**：已接受，待应用
- 🚧 **In Progress**：正在应用/开发
- ✔️ **Completed**：已完成并归档
- ❌ **Rejected**：已拒绝
- 🔄 **Revision Needed**：需要修改
