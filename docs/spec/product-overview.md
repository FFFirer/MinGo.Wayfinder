## 技术架构

### 后端

- **框架**: ASP.NET Core Web API
- **数据库**: SQLite（开发）/ PostgreSQL（生产）
- **ORM**: Entity Framework Core
- **架构**: 整洁架构 + 领域驱动设计

### 前端

- **框架**: SolidJS
- **UI**: daisyui + TailwindCSS v4
- **设计**: Material Design 3
- **模式**: SPA
